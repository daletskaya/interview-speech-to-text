# Словарь расшифровки

Слова, которые помогают распознать запись точнее. Заполнять не обязательно.
Если не знаете, что писать, — попросите Claude, он разберётся сам.

Положите этот файл в папку с записями, и он подхватится.

## Термины

Слова, которые часто звучат в разговоре. Пишите внутрь блока, по одному
на строку. Полутора десятков хватит, больше — хуже.

```
корзина
чекаут
промокод
онбординг
```

## Замены

Что на что менять, если распознавание ошибается одинаково раз за разом.

```
крикабельн -> кликабельн
```

## Бренды

Названия продуктов, компаний и сервисов, которые могут всплыть в разговоре.
Пишите обычным текстом, в том виде, в каком они должны попасть в расшифровку.
