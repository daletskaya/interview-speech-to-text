# Словарь расшифровки

Пустая заготовка — заполни под свой проект. Чем лучше заполнена, тем меньше
придётся править руками: распознаватель постоянно перевирает названия
продуктов, компаний и профессиональный жаргон.

Если словарь не трогать, скилл всё равно будет работать — просто имён
собственных в расшифровке будет больше перевранных.

Скрипт ищет `глоссарий.md` сначала в папке с записями, потом берёт этот файл.
Так можно держать свой словарь на каждый проект, не трогая скилл.

Разделы читают разные участники, и это важно не перепутать:

| Раздел | Кто читает | Когда |
|---|---|---|
| Термины | модель распознавания | перед тем, как слушать запись |
| Замены | скрипт | сразу после распознавания |
| Бренды | Claude | при вычитке готового текста |

**Термины и Замены читает программа**, поэтому слова в них пишутся внутри
блоков кода. Всё, что вне блоков, программа не видит — там можно писать
пояснения как угодно.

**Бренды читает Claude глазами**, как обычный текст. Их можно писать свободно,
блоки не нужны. В распознавание они не попадают: это шпаргалка, с чем сверить
искажённое название, прежде чем поставить `(нрзбр)`.

Почему бренды не подсказываются модели: подсказка должна быть короткой.
Длинный список названий заставляет модель слышать их там, где их нет. Если
интервью целиком про один сервис, перенеси его в «Термины» руками — одно-два
названия подсказке не повредят.

## Термины

Слова, которые подсказываются модели перед распознаванием: она охотнее узнаёт
их в потоке речи. Сюда — то, что в интервью звучит часто.

**Список держи коротким**, полтора десятка слов. Длинная подсказка начинает
искажать текст: модель принимается слышать подсказанные слова там, где их нет.

```
корзина
чекаут
промокод
онбординг
```

## Замены

Ошибки, которые распознаватель делает стабильно. Применяются к готовому
тексту: с начала слова, без учёта регистра, окончание свободно — поэтому
«крикабельн» поймает и «крикабельная», и «крикабельные».

Вноси сюда только однозначное. Замена вслепую опаснее опечатки: похожее
слово может оказаться обычным словом из речи, и текст станет врать.

```
крикабельн -> кликабельн
```
