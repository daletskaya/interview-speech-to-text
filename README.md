# Расшифровка интервью

Скилл для Claude Code. Превращает запись созвона в расшифровку: диалог
с именами и тайм-кодами, по которым можно найти нужный момент в видео.

Сделан под интервью с пользователями, но годится для любого разговора.
Работает с записями любой платформы: Телемост, Zoom, Meet.

## Как поставить

1. Скачайте репозиторий кнопкой **Code → Download ZIP** и распакуйте.
2. Положите папку в `~/.claude/skills` — её видно в Finder по
   **Shift+Cmd+G** и пути `~/.claude/skills`.
3. Откройте Claude Code и скажите: «расшифруй интервью», приложив файлы
   записи.

Больше ничего делать не нужно. Всё, что требуется для работы, Claude
доставит себе сам при первом запуске — и сам скажет, если ему что-то
понадобится от вас.

## Что он сделает

- склеит записи, если созвон писался кусками;
- распознает речь;
- разберётся, кто из участников что говорил;
- соберёт диалог с тайм-кодами;
- отдельно покажет места, которые не расслышал, — чтобы вы их вспомнили.

Получится примерно так:

```
[02:14] Интервьюер: А что вы сделали дальше, когда увидели этот экран?

[02:19] Гость: Растерялась, если честно. Я искала, где поменять дату,
а тут сразу просят оплатить. Пришлось возвращаться назад и начинать
сначала.
```

## Можно подсказать свои слова

В папке скилла лежит `glossary.md` — пустой файл под названия продуктов,
компаний и профессиональные словечки, которые встретятся в разговоре.
Распознаватель постоянно перевирает такое, а подсказанное узнаёт лучше.

Заполнять не обязательно, без словаря скилл тоже работает. Но если вы
ведёте интервью про один и тот же продукт, десять минут на словарь
окупятся на первой же расшифровке.

## Что важно знать

**Запись никуда не уходит.** Речь распознаётся на вашем компьютере, в
интернет ничего не отправляется.

**Первый запуск дольше остальных.** Claude скачивает модель распознавания,
это пара гигабайт. Дальше она лежит на диске и больше не скачивается.

**Считается не мгновенно.** Час записи обрабатывается примерно полчаса.
Можно оставить и заняться своими делами.

**Расшифровку нужно прочитать.** Распознавание ошибается: путает названия,
иногда приписывает реплику не тому человеку. Claude честно пометит, где
не расслышал, и расскажет, где разметка шаткая, — но последнее слово
за человеком, который был на интервью.

## Если что-то пошло не так

Скажите об этом Claude своими словами — он разберётся сам. Внутри скилла
для него написано, что делать с типичными поломками.
